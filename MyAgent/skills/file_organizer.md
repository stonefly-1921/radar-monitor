# File Organizer Skill

## 简介
文件整理技能，帮助整理和归类文件。

## 使用场景
- 按类型整理文件（图片、文档、代码等）
- 批量重命名文件
- 创建目录结构

## 工具使用
- `file_list` - 列出目录内容
- `shell_run` - 执行文件操作命令（Windows: dir, move, copy）
- `file_write` - 创建新文件或目录说明

## 工作流程
1. 列出当前目录文件
2. 分析文件类型和特征
3. 创建分类目录
4. 移动文件到对应目录
5. 生成整理报告

## 文件类型识别
- 文档: .txt, .doc, .docx, .pdf, .md
- 代码: .py, .js, .java, .cpp, .c
- 图片: .jpg, .png, .gif, .bmp
- 数据: .csv, .json, .xml, .xlsx

## 命名规范建议
- 使用英文或拼音
- 避免特殊字符
- 添加日期前缀便于排序
