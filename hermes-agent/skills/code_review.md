# Code Review Skill

## 简介
代码审查技能，帮助审查代码质量、发现问题和建议改进。

## 使用场景
- 审查 Python、JavaScript 等代码文件
- 检查潜在 bug 和安全问题
- 提供代码改进建议

## 工具使用
- `file_read` - 读取代码文件
- `shell_run` - 运行 lint 工具（如 pylint, eslint）
- `python_run` - 执行代码分析脚本

## 工作流程
1. 读取目标代码文件
2. 分析代码结构和逻辑
3. 检查常见问题（命名、格式、逻辑错误）
4. 生成审查报告

## 输出格式
```markdown
## 代码审查报告

### 文件信息
- 文件路径: xxx
- 代码行数: xxx

### 发现的问题
1. [问题描述] (严重程度: 高/中/低)
   - 位置: 行号
   - 建议: 修复方式

### 改进建议
- 建议1
- 建议2

### 总体评价
[好/一般/需要大幅改进]
```
