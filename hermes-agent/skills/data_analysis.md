# Data Analysis Skill

## 简介
数据分析技能，帮助分析和处理数据文件。

## 使用场景
- 分析 CSV、JSON 数据文件
- 生成数据统计
- 数据清洗和转换

## 工具使用
- `file_read` - 读取数据文件
- `python_run` - 执行数据分析脚本
- `file_write` - 输出分析结果

## 工作流程
1. 读取数据文件
2. 了解数据结构
3. 执行分析（统计、聚合、筛选等）
4. 生成分析报告

## 常用分析
- 记录数统计
- 字段分布
- 缺失值检查
- 排序和筛选
- 数据转换（CSV转JSON等）

## 输出格式
```markdown
## 数据分析报告

### 数据概况
- 文件: xxx
- 记录数: xxx
- 字段数: xxx

### 统计信息
| 字段 | 类型 | 非空数 | 示例值 |
|------|------|--------|--------|

### 分析结果
[具体分析结果]

### 建议
[基于数据的建议]
```
