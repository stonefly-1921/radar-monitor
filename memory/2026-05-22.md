### xlsx_read Bug 分析报告

**症状**: xlsx_read 返回 PowerShell 脚本内容本身（如 `$excel = New-Object...`），而非 Excel 数据

**测试验证**:
- `_debug_A.py`: 直接 subprocess + `-File` → ✅ 正确输出 `Product`tQty`nA`t100`
- 通过工具注册表调用 `_run_ps_file` → ❌ 返回脚本内容

**根因**: `_run_ps_file` 使用 `encoding='utf-8-sig'` 写临时 .ps1，PowerShell 用系统 codepage 读，导致编码冲突，脚本未被执行而是被输出

**修复方案**: 改用 `-EncodedCommand` 传 base64 编码的脚本，不依赖临时文件

**待修复代码位置**: `MyAgent/tools/docx_ops.py` 第39-52行

### 后续任务

### 修复步骤（等write工具恢复后执行）

在 `tools/docx_ops.py` 中找到 `_run_ps_file` 函数（约第39-52行），将：

```python
def _run_ps_file(script, timeout=120):
    """Run PowerShell via temp .ps1 file (for complex data scripts)."""
    with tempfile.NamedTemporaryFile(mode='w', suffix='.ps1', encoding='utf-8-sig', delete=False) as f:
        f.write(script)
        temp_path = f.name
    try:
        result = subprocess.run(
            ['powershell', '-NoProfile', '-NonInteractive', '-File', temp_path],
            capture_output=True, text=True, timeout=timeout
        )
        return result.stdout.strip(), result.stderr.strip(), result.returncode
    finally:
        os.unlink(temp_path)
```

替换为：

```python
def _run_ps_file(script, timeout=120):
    """Run PowerShell via -EncodedCommand (avoids temp file encoding issues)."""
    encoded = base64.b64encode(script.encode('utf-16-le')).decode('ascii')
    result = subprocess.run(
        ['powershell', '-NoProfile', '-NonInteractive', '-EncodedCommand', encoded],
        capture_output=True, text=True, timeout=timeout
    )
    return result.stdout.strip(), result.stderr.strip(), result.returncode
```
